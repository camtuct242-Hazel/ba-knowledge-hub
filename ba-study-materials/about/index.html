Hệ thống Chuẩn mực Tham chiếu Quốc tế Mở Open International Reference Standards

Để đảm bảo tính chuẩn xác và giá trị ứng dụng lâu dài, mọi thuật ngữ và quy trình trên website đều tuân thủ chặt chẽ các tài liệu chuẩn công nghiệp sau: To ensure rigorous accuracy and long-term industry value, all terminology and workflows strictly adhere to the following standard frameworks:

[BABOK® v3]

IIBA BABOK Guide v3

A Guide to the Business Analysis Body of Knowledge - Khung khái niệm BACCM, các kỹ thuật khơi gợi, và quy trình quản trị vòng đời yêu cầu. The global standard for business analysis practice, covering BACCM concepts, elicitation techniques, and requirements lifecycle management.

[OMG BPMN™ 2.0]

OMG BPMN 2.0 Specification

Business Process Model and Notation - Chuẩn mực mô hình hóa quy trình nghiệp vụ với Pools, Lanes, Events, Activities và Gateways chính xác. Business Process Model and Notation standard for cross-functional business workflows, pools, swimlanes, and gateways.

[OMG UML® 2.5]

OMG Unified Modeling Language 2.5

Ngôn ngữ mô hình hóa thống nhất cho hệ thống phần mềm: Sơ đồ Use Case, Activity, Sequence và State Machine. Standard modeling specification for software systems: Use Case, Activity, Sequence, and State Machine diagrams.

[Agile & Scrum]

Agile Alliance & Scrum Guide

Tuyên ngôn Agile, nguyên lý Scrum thực chiến, tiêu chí User Story INVEST và tiêu chí sẵn sàng / hoàn thành (DoR / DoD). Agile Manifesto principles, empirical Scrum workflows, INVEST User Story criteria, and Definition of Ready / Done gates.

[ANSI / ISO SQL]

Relational Model & ANSI SQL

Lý thuyết cơ sở dữ liệu quan hệ của E.F. Codd, chuẩn hóa dữ liệu 1NF-3NF, mô hình ERD và chuẩn truy vấn dữ liệu SQL quốc tế. Codd's relational database foundation, 1NF to 3NF normalization rules, ERD models, and ANSI SQL query specifications.

[IETF & ISTQB]

IETF RFC HTTP & ISTQB QA

Chuẩn giao thức mạng IETF RFC (HTTP Methods, Status Codes, JSON) và nguyên lý kiểm thử phần mềm nền tảng của ISTQB. IETF RFC protocol standards (HTTP methods, status codes, JSON payload) and ISTQB Foundation software testing principles.
