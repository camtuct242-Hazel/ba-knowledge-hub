💡 Hướng dẫn Nhập dữ liệu Flashcard vào Anki How to Import Flashcards into Anki
  1. Mở ứng dụng Anki trên máy tính của bạn và chọn File -> Import.Open Anki on your computer and select File -> Import.
  2. Chọn tệp ITBA_Flashcards_Deck.csv vừa tải về.Select the downloaded ITBA_Flashcards_Deck.csv file.
  3. Thiết lập: Field separator: Comma (Dấu phẩy), Allow HTML in fields: Checked.Ensure settings: Field separator: Comma, Allow HTML in fields: Checked.
  4. Ánh xạ các trường: Cột 4 (Front_Prompt) ánh xạ vào mặt trước Front, Cột 5 (Back_Answer) ánh xạ vào mặt sau Back, Cột 2 (Category) ánh xạ vào Tags.Map fields: Column 4 (Front_Prompt) to Front, Column 5 (Back_Answer) to Back, Column 2 (Category) to Tags.
